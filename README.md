# 🚇 Sistema de Bilhete Único

## 🌟 Descrição do Projeto
O **Sistema de Bilhete Único** foi desenvolvido para gerenciar o bilhete de transporte de passageiros, associando um número de identificação único a cada usuário. O sistema permite a aplicação de tarifas diferenciadas com base no perfil do usuário (**Normal, Estudante ou Professor**).

Principais funcionalidades incluem:
- Carregamento de saldo;
- Consulta de saldo;
- Uso do bilhete nas catracas de transporte.
